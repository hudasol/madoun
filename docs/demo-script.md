# Demo script (3 minutes)

1. **Control tower** (`/`): each line is a shipment; the bar shows whether approvals finish before arrival. Drag the time scrubber back to watch the day replay.
2. **Open a shipment**: the evidence file shows who has checked what, which receipts were reused, and why the lane is green, amber or red. Override the lane to see an officer decision logged.
3. **Exceptions**: every blocker has a named owner and a clock; resolve one.
4. **Evidence**: receipts with provenance, sharing policy and the hash-chain check.
5. **Learning**: suggestions from outcomes; preview the effect, then approve one.
6. **Inspection**: run a simulated robot inspection; the result becomes shared evidence.
7. **Today vs Madoun**: modelled comparison on the synthetic week. Switch to Arabic and light theme.
